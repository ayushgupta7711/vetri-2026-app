VETRI 2026 – PREMIUM OFFLINE PWA

Deploy the CONTENTS of this folder to the root of your GitHub Pages repository (main branch, / root). Do not upload the ZIP itself. Keep the icons folder and its contents.

After committing, wait for GitHub Pages deployment to finish. Open the Pages URL in Safari (iPhone) or Chrome (Android), then Add to Home Screen / Install app. Open once online to cache the app for offline use.

Progress, bookmarks, incorrect-question list, mock history and theme preference are stored locally in each browser/device. They do not sync across devices. Clearing browser site data can erase progress.

Question bank integrity: the original QUESTIONS data array was retained byte-for-byte during this interface update. No question, option, answer key, page reference or explanation was edited.
